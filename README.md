# 🏰 Kolhapur Kult — City Exploration & Tourism Web Application

> **An interactive, responsive digital tourism platform celebrating the royal Maratha heritage, sacred temple sanctums, hill forts, and cultural treasures of Kolhapur, Maharashtra.**

Developed by **Tejas Khandekar**  
Portfolio: [Tejas Khandekar Portfolio](https://tejas-khandekar-portfolio.netlify.app) • [LinkedIn](https://linkedin.com/in/tejas-khandekar) • [GitHub](https://github.com/tejas1828)

---

## 🌟 Highlights & Features

- **Cinematic Ambient Hero**: Fullscreen background video with smooth overlay, dynamic typography, and royal Maratha theme branding.
- **8 Handpicked Landmarks**: Individual immersive showcase pages with multi-image galleries, historical background, architecture details, and direct Google Maps navigation links.
- **Fully Responsive Architecture**: Designed using modern CSS Grid and Flexbox for seamless browsing on mobile phones, tablets, laptops, and ultra-wide screens.
- **Interactive User Authentication**: Client-side registration and login system with `localStorage` persistence and animated feedback.
- **Interactive Geographic Exploration**: Built-in Google Maps integrations for every destination and an interactive city map overview.
- **Zero-Dependency Lightweight Build**: Fast pure HTML5, CSS3, and modern Vanilla JavaScript with FontAwesome icons and Google Fonts.

## 📍 Featured Destinations

| # | Destination | Category | Significance |
|---|-------------|----------|--------------|
| 1 | **Shree Mahalakshmi Temple** (`mh.html`) | Spiritual Sanctum | 7th-century Chalukya architectural marvel & sacred Shakti Peetha of Goddess Ambabai. |
| 2 | **Shree Jotiba Temple** (`jotiba.html`) | Hilltop Pilgrimage | Perched at 3,124 ft in Wadi Ratnagiri, famous for the Chaitra Poornima pink gulal festival. |
| 3 | **Bhavani Mandap** (`bhavani.html`) | Royal Court | Historic administrative seat of Chhatrapati Shahu Maharaj with taxidermy & arms collection. |
| 4 | **New Palace & Museum** (`newpalce.html`) | Royal Heritage | 1884 black polished stone palace featuring the Shree Chhatrapati Shahu Museum. |
| 5 | **Kaneri Math Museum** (`kaneri.html`) | Cultural Museum | Siddhagiri Gramjivan open-air sculpture village illustrating traditional rural Indian self-reliance. |
| 6 | **Panhala Fort** (`panhala.html`) | Maratha Citadel | Largest Deccan hill fort, celebrated for Chhatrapati Shivaji Maharaj's historic escapes & Teen Darwaza. |
| 7 | **Rankala Lake** (`rankala.html`) | Scenic Promenade | Historic 9th-century reservoir with evening promenade, boating, Padmaraje Garden & local cuisine. |
| 8 | **Shri Kopeshwar Temple** (`kope.html`) | Ancient Stone Marvel | 12th-century Shilahara temple at Khidrapur with the circular open-sky Swargamandap. |

## 🚀 How to Run Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/tejas1828/explore-kolhapur.git
   ```
2. Navigate into the project folder:
   ```bash
   cd "explore-kolhapur"
   ```
3. Open `index.html` in any web browser (Chrome, Edge, Firefox, Safari) or use VS Code Live Server:
   - Double click `index.html`, OR
   - Run `npx serve .` / `python -m http.server 8000`

## 📤 How to Push to GitHub

To publish this project to your GitHub account (`tejas1828`):

1. **Open PowerShell or Terminal** in this project folder:
   ```powershell
   cd "c:\Users\Tejas\OneDrive\Desktop\WebM2\My Project"
   ```

2. **Initialize a Git repository**:
   ```bash
   git init
   ```

3. **Stage and commit all files**:
   ```bash
   git add .
   git commit -m "Initial commit: Kolhapur Kult Tourism Web Application"
   ```

4. **Create a new repository on GitHub** (e.g. `explore-kolhapur` or `kolhapur-kult`):
   - Go to [github.com/new](https://github.com/new)
   - Name it `explore-kolhapur` (or `kolhapur-kult`)
   - Leave it empty (without initializing README)

5. **Link and push to GitHub**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/tejas1828/explore-kolhapur.git
   git push -u origin main
   ```

6. **Enable GitHub Pages (Optional for Live Demo)**:
   - Go to your repository on GitHub → **Settings** → **Pages**.
   - Under **Build and deployment**, select `Deploy from a branch`.
   - Choose `main` branch and `/ (root)` folder → Click **Save**.
   - Your site will be live at `https://tejas1828.github.io/explore-kolhapur/`!
